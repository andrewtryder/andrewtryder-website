PoaIndex

Historical turfgrass evaluation data synthesis and evidence-based cultivar recommendations.

The Problem

The National Turfgrass Evaluation Program (NTEP) publishes valuable agronomic trial data, but the records are dispersed across decades of disparate PDF and tabular reports. Comparing turfgrass cultivars across multiple multi-year trial cycles and identifying varieties proven to perform in specific geographic regions requires laborious manual cross-referencing.

The Approach

PoaIndex extracts, audits, and normalizes historical trial results into a structured turfgrass quality corpus. Its recommendations weigh local trial evidence, regional multi-year support, recency, and confidence adjustments; turf-zone information is presented separately as supporting context.

Selected Features
  • Curated historical quality corpus covering multiple grass species and multi-year trial cycles.
  • Recommendations informed by local trial evidence, regional support, recency, and confidence.
  • Cultivar search and side-by-side trial quality comparisons.
  • Read-only edge API designed for high-availability querying without credential barriers.
  • Clean static web exploration interface requiring zero account creation.
Technical Description
Ingestion & certification pipeline built in Node.js and TypeScript. Read-only HTTP API hosted on Cloudflare Workers backed by Cloudflare D1 serverless SQLite. Static web front end built with Vite and React. Cold-storage source archive stored in Cloudflare R2.
Source code is private. Visit live website (poaindex.com) →

NH Fuel Watch

Civic heating-fuel price transparency and municipal provider discovery for New Hampshire residents.

The Problem

Residential heating oil and propane pricing varies considerably across New Hampshire suppliers and fluctuates frequently throughout the winter. Because pricing is scattered across dozens of individual company websites, homeowners lack a centralized, neutral reference for posted cash rates or seasonal price trends.

The Approach

NH Fuel Watch is an independent public-benefit information resource for provider-published prices and service-area details. It is not a broker, middleman, or marketplace; each recorded observation includes its source and when that source was checked. Advertised prices may differ from a provider's final delivered price.

Selected Features
  • Tracked public price observations for #2 heating oil and propane where providers publish them.
  • Provider discovery based on documented municipal service coverage.
  • Price observations recorded as immutable integers in mills ($0.001) with source disclosures.
  • Historical price trend visualizations across seasons and regions.
  • Source links and observation dates to support direct verification with each provider.
Technical Description
Full-stack TypeScript application built with React Router v8 using Server-Side Rendering (SSR). Deployed on Cloudflare Workers edge runtime with Cloudflare D1 serverless SQLite. Includes automated scheduled ingestion pipelines with fixture-based scraper verification.
Source code is private. Visit live website (nhfuelwatch.com) →
