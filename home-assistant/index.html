Home Assistant Integrations

A complete index of custom Home Assistant integrations I have authored and published. Each component bridges real-world devices, utilities, and communication services into local smart home dashboards and automations.

Integration Functional Description Source
eBay Read-only activity monitor exposing watched items, bidding activity, active listings, seller operational metrics, and account health via sensors, events, and calendar entities. GitHub →
EcoWater Cloud Asynchronous integration for EcoWater cloud-connected water softeners and treatment systems, monitoring daily water consumption, salt level status, and device operational telemetry. GitHub →
Eversource Rates Retrieves public Eversource electricity tariffs to provide live USD/kWh rates for the Home Assistant Energy dashboard, with optional monitoring of municipal-level electrical outage reports. GitHub →
Hero Health Home Assistant integration for the Hero smart medication dispenser, tracking schedule adherence, doses taken and missed, refill reminders, and cartridge pill levels. GitHub →
iGuardStove Monitors iGuardStove / iGuardFire status, temperature, lockout state, and activity events. Optional Master Lock control is disabled by default; remote unlock requires a separate explicit setting. GitHub →
myQ Garage Read-only garage door cover integration that synchronizes with an external Cloudflare Worker parsing real-time myQ notification emails to report door open/closed status reliably. GitHub →
Smart Oil Gauge Connects heating oil storage tanks to Home Assistant via Connected Consumer Fuel web services, exposing gallons remaining, tank percentage, daily burn rates, and runout projections. GitHub →
SunsetHue Integrates with the SunsetHue developer API to provide multi-day sunrise and sunset quality predictions, cloud coverage metrics, event azimuth, and golden/blue hour periods. GitHub →
VoIP.ms Comprehensive integration for VoIP.ms accounts, providing balance sensors, SIP registration binary sensors, inbound SMS webhook event triggers, and an outbound SMS service. GitHub →

Maintenance: These are open-source custom integrations, each maintained in its own public repository with documentation and installation guidance.
